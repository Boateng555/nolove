|------|---------|
| `ask.gif` or `ask.jpg` | First page — "Will you go on a date?" |
| `yay.png` | "WAIT YOU ACTUALLY SAID YES" page |
| `profile.jpg` | Final page — circular avatar |

## Optional food photos

Then uncomment the `<img>` lines in `proposal/templates/proposal/food.html`.
